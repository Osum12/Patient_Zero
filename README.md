# Patient Zero

An interactive genetics mystery for AP Biology (Unit 5: Heredity). Students play a genetic counselor
tracing a fictional autosomal recessive disorder, Keller Syndrome, through the four-generation Okafor
pedigree to find the family's "patient zero."

## Play

Open `index.html` in any modern browser. It's one self-contained file and works offline from `file://`.
Progress saves to the browser's localStorage, and the Reset button clears it.

## Customize

All names, dialogue, evidence and asset paths are plain JS objects at the top of the `<script>` in
`index.html`. See [CONTENT.md](CONTENT.md) for the list of placeholder audio clips and portraits to record or create.
